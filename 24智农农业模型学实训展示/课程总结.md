# 农业模型学实训课程总结与改进方向

> 总结依据：51 份个人工作日志 + 1 份小组日志 + 1 份发布组B 实训总结报告
> 实训周期：2026年6月29日 — 7月2日（4天）
> 参与人数：55人，分5个功能组
> 项目基础：CN-strawberryDSSAT 系统（DSSAT 作物模型 Python 重构 + Docker 部署）

---

## 一、已取得的成果

### 1.1 模型对齐

科研组A 将 Python 重构模型与 DSSAT Fortran 原版的 8 项核心指标偏差从 -100% 压至 ±10% 以内，达标率从 0/8 提升至 8/8。关键技术突破包括：LAI 公式补种植密度参数、线性 RUE 替换为 PHOTO.for 光饱和曲线、实现 VSSINK 源汇调控、引入 Parton-Logan 八点温度模型、温度响应曲线改为 QDR 二次曲线。所有生物量误差控制在 1% 以内。

### 1.2 模型对比

科研组B 完成了 Python 模型与 Docker 版 DSSAT 数据的系统性交叉对比，解决了单位差异问题（生物量差 50 倍、果实数量差 50000 倍），将果实数量相关系数从 0.384 提升至 0.588。部署了 GUI 版与 Docker 命令行版双版本运行环境并验证一致性。

### 1.3 代码与测试

完成 39 个标准化测试用例编写，13 项单元测试全部通过，三个实验文件验证零差异通过。核心源码 8 个主要计算函数添加完整中文注释，绘制 3 张 UML 图。Dockerfile 镜像源优化将 apt-get update 从 800-1200 秒降至 3-6 秒。

### 1.4 可视化与展示

完成 96 张图表高清重导出（dpi=600），嵌入网页全部 86 张图文。完成草莓全生长周期动态效果图、年度数据对比图、核心指标对比分析图表。发布组B 完成项目展示网页本地开发，实现零代码内容管理系统、单文件 HTML 合并、Base64 资源内嵌。

### 1.5 文档与规范

产出四份标准化文档、《实训实验报告完整版.md》、5 套通用 MD 模板、《Markdown 文档编写规范.md》、《项目文件归档规范.md》、《GitHub 实操教学指引》、《DSSAT 输入输出文件注释.md》、《DSSAT 模型运作原理.md》等完整文档体系。

## 二、本科生可实现的改进方向

### 2.1 模型机理深化（难度：中高）

**现状**：LAI 只增不减、SLA 一次性突变、物候仅积温驱动无光周期调控、生长呼吸转换效率未优化。这些是模型本身的功能缺失，学生操作代码时发现了问题但未实现修复。

**改进内容**：
- 补充 LAI 叶片衰老衰减逻辑（参照 DSSAT 的 SLA 衰减机制，在 Python 代码中实现日长驱动的叶片衰老计算）
- 实现物候光周期调控子模块（当前仅积温驱动，需增加日长参数参与花芽分化判定）
- 优化生长呼吸转换效率系数（参照 DSSAT Fortran 源码中的 RESP.for 模块）

**可行性**：科研组A 已产出《模块机理核对记录_综合版.md》和《参数物理意义与取值说明.md》，机理研究组对问题已定位清楚，代码修改范围明确（主要集中在 `cropgro_strawberry.py` 的 `update_lai()` 和 `update_phenology()` 函数）。本科生具备 Python 编程基础即可推进。

**验收标准**：修改后 LAI 在生育后期出现自然下降趋势，光周期参数参与物候期判定，模拟结果与 DSSAT 输出的偏差不增大。

### 2.2 全生育期模拟与回归验证（难度：中）

**现状**：因 Python 环境故障仅完成 60 天样例，冯桂婷实现 84 天模拟但完整需 120-150 天。回归验证未完成。

**改进内容**：
- 扩展气象数据至完整生长周期（120-150天，覆盖种植到收获全过程）
- 运行全生育期模拟并输出完整数据
- 编写回归验证脚本，对照 DSSAT 逐日输出验证 Python 模型一致性

**可行性**：气象数据已有 4 组实验文件，仅需补充缺失天数。回归验证脚本可基于已有 compare.py 扩展。冯桂婷已修复 4 个数据加载 bug，数据管道已通。

**验收标准**：完成 365 天完整模拟，8 项核心指标在全生育期内偏差均控制在 ±15% 以内。

### 2.3 线上部署与备选方案（难度：中）

**现状**：Netlify 部署失败，已有单文件 HTML 和 Git 仓库。

**改进内容**：
- 排查 Netlify 构建配置错误（环境变量、文件路径），完成线上部署
- 同时准备 GitHub Pages 和 Vercel 两个备选部署方案
- 编写部署操作文档

**可行性**：杨艳鸿已有单文件 HTML（Base64 内嵌资源，无外部依赖），部署仅需配置正确的构建命令和发布目录。GitHub Pages 部署更为简单，本科生完全可操作。

**验收标准**：三个部署方案中至少两个成功生成可公开访问的链接，部署文档可复现。

### 2.4 可视化图表自动化生成（难度：中）

**现状**：罗晓羽使用 matplotlib 手动复刻 DSSAT 图表，效率低且样式偏差大。

**改进内容**：

- 自动生成标准对比图表（LAI、生物量、产量、根深等核心指标的时间序列对比）
- 支持多实验批量出图，统一配色和标注规范

**可行性**：已有 draw_plot.py 绘图脚本作为基础，matplotlib 是本科生常用工具。关键是建立标准化的图表模板和数据接口。

**验收标准**：一键生成至少 8 张核心指标对比图，图表风格统一，数据准确。
